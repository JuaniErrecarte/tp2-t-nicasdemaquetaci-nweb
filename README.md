
ALUMNO: ERRECARTE JUAN IGNACIO

NOMBRE DEL PROYECTO: PRESENCIA WEB PARA "CENTRO FOMENTO DE HERNANDEZ"

DESCRIPCIÓN DE LA INSTITUCIÓN: El Centro de Fomento de Hernández es una institución civil que se encuentra en la localidad de Hernández (La Plata). Funciona como el principal espacio de encuentro, contención e integración social para los vecinos de la zona.

En el, se desarrollan diversas disciplinas deportivas, talleres artísticos y formativos para todas las edades, y cuenta además con una Biblioteca Popular que ofrece espacio de lectura, consulta y préstamo de libros
